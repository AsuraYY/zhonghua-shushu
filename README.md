# zhonghua-shushu · 中华传统占卜术数 Skill

一个面向 AI 智能体的**中华传统术数领域技能包**：覆盖命理、占卜、相术风水、择日起名等 20 余种术数的知识讲解、排盘起卦实操、场景选型、案例教学与模板套用，内置**零依赖 Python 脚本层**负责确定性计算，并内置严格的理性边界与反诈骗条款。

> **定位**：懂古典术数，也懂现代理性边界的传统文化顾问。
> **重要声明**：本仓库内容属**传统文化与民俗研究**范畴，仅供文化学习、娱乐与参考，**不构成**医疗、法律、投资、婚姻、生育等任何重大决策依据。

## 一、这个 Skill 能做什么

| 能力 | 说明 |
| --- | --- |
| 知识讲解 | 20+ 种术数的起源、原理、术语白话解释、流派争议标注 |
| **脚本排盘（先算后解）** | 纯标准库 Python 脚本算八字 / 六爻 / 梅花 / 择日 / 五格，模型只负责解读，杜绝心算与背表出错 |
| 排盘起卦 | 八字四柱、大运起运、六爻装卦（纳甲/世应/六亲）、梅花起卦体用、紫微安星、择日、五格姓名 |
| 场景选型 | 决策树 + 场景推荐表：问一事用卦占，问一生用命理，问环境用风水，问日子用择日 |
| 案例教学 | 每术一条完整虚构推理链，数据均经核算 |
| 模板套用 | 八字简批、断卦、择日、风水、起名等可直接套用的输出骨架 |
| 避坑指南 | 常见骗局识别 + 拒绝话术（拒绝宿命论恐吓与收费改运敛财） |

覆盖术数：四柱八字、紫微斗数、铁板神数、称骨、达摩一掌经、鬼谷子两头钳、六爻纳甲、梅花易数、周易卦爻辞、大六壬、奇门遁甲、太乙神数、文王课/金钱课、面相、手相、风水堪舆、姓名学、测字、择日、果老星宗/七政四余、米卦/鸟卦/扶乩/抽签等民俗占法。

## 三、脚本层：先算后解

**心智模型：脚本出数值，模型出解读。** 凡是「能算出来的」，都不许让模型当场心算或凭记忆背表。

```bash
# 八字（推荐给出生地经度）
python3 scripts/bazi.py --datetime "1990-04-12 10:30" --gender male --lon 116.41 --years 2026,2027

# 六爻（6老阴 7少阳 8少阴 9老阳，自下而上）
python3 scripts/liuyao.py --values 7,8,7,8,7,8 --date 2026-10-16 --question-type 财

# 梅花（两数起卦）
python3 scripts/meihua.py --numbers 3,8

# 择日
python3 scripts/zeri.py --from 2026-11-01 --to 2026-11-30

# 五格（笔画须按繁体自行提供）
python3 scripts/wuge.py --surname-strokes 11 --given-strokes 8,7
```

- 纯 Python 标准库、**零依赖**，Python 3.8+ 即可；多数脚本支持 `--json`；`--help` 查全部参数。
- 完整参数、数据来源与精度、「刻意不做的事项」见 [references/09-scripts.md](references/09-scripts.md) 与 [scripts/README.md](scripts/README.md)。
- **脚本不覆盖**：六壬 / 奇门 / 太乙 / 玄空 / 紫微安星 / 称骨 / 公历⇄农历换算 / 宜忌表 / 黄黑道 / 二十八宿。遇到这些请用专业排盘工具或查通书，**不要假装算过**。

### 精度与边界

| 项目 | 精度 / 覆盖 |
| --- | --- |
| 二十四节气 | 1900–2052 查 DE421 预计算表；与公开万年历秒值最大差 34 秒 |
| 超出 1900–2052 | 退回近似公式，**脚本显式打印「近似值」警告**，误差可达十余分钟 |
| 日柱干支 / 六十四卦 | 精确（儒略日三点交叉校验 / 由八宫表推导生成） |
| 真太阳时 | 经度时差精确；均时差近似式，年较差约 ±0.6 分钟 |

脚本输出出现「⚠️ 近似值」时，必须在回复中如实告知用户精度受限。

### 改动脚本后的三道校验

```bash
python3 scripts/_selftest.py             # 数值层：脚本算得对不对
python3 scripts/_tools/audit_vs_doc.py   # 文档层：脚本常量与 08-algorithms.md 表格逐格一致
python3 scripts/_tools/audit_commands.py # 命令层：文档里的命令照抄能不能跑通
```

三个都要绿。只跑 `_selftest.py` 查不出「脚本里的表与文档里的表抄得不一样」，前两层也查不出「文档命令混进中文、照抄即报错」。项数随迭代变化，以运行输出为准。

## 四、安装与使用

### 环境要求

- **Python 3.8+**（仅脚本层需要；纯标准库，无需 `pip install` 任何依赖）
- 若需重建节气数据表，才需要 `pip install skyfield numpy` 与 DE421 星历文件（见 `scripts/_tools/gen_solar_terms.py`）

### 安装

将本仓库整个目录放入技能目录即可：

- **用户级**（对所有项目生效）：`~/.workbuddy/skills/zhonghua-shushu/`
- **项目级**（仅当前项目生效）：`{workspace}/.workbuddy/skills/zhonghua-shushu/`

```bash
# 用户级安装示例
git clone https://github.com/AsuraYY/zhonghua-shushu.git \
  ~/.workbuddy/skills/zhonghua-shushu
```

### 触发方式

在对话中提到下列任一内容即可自动触发：

`八字` / `子平` / `紫微` / `斗数` / `六爻` / `纳甲` / `梅花易` / `周易` / `六壬` / `奇门遁甲` / `太乙` / `称骨` / `一掌经` / `风水` / `堪舆` / `玄空` / `八宅` / `择日` / `黄历` / `姓名学` / `测字` / `面相` / `手相` / `果老星宗` / `七政四余`

或提出这类问题：

- 「该用哪种术数看这件事？」
- 「帮我排个八字 / 起一卦」
- 「这个命盘 / 这卦怎么看？」
- 「下周搬家哪天日子好？」

### 按需加载

`SKILL.md` 是入口，实操细节拆在 `references/` 中，**只加载当前问题需要的章节**，避免上下文浪费。

### 典型调用流程

```
收齐参数 → python3 scripts/xxx.py → 照抄脚本数值 → 套模板解读 → 边界声明
```

## 五、硬性规则（使用本 Skill 时必须遵守）

1. **边界声明**：每次解读前后都声明「传统文化与民俗参考，不构成重大决策依据」。
2. **禁止**：宿命论恐吓、伪科学断言、收费改运/开光/消灾敛财话术、鼓励沉迷或频繁占问。
3. **健康/心理/安全**议题一律建议就医或寻求专业帮助，术数不能替代诊疗。
4. **隐私**：不索取、不复述真实第三方隐私；案例一律虚构。
5. **传承争议要标注**（如铁板神数、梅花易数托名问题），不冒充「唯一正统」。
6. **脚本优先（硬要求）**：排盘 / 起卦 / 装卦 / 历法换算一律**先跑 `scripts/` 里的脚本**，再照抄脚本数值解读，不要用心算或凭记忆背表替代。
   - 声明「已复核」必须能指认脚本名与关键输出（如「`scripts/bazi.py` 排得日柱=丁未」）；**没跑脚本不得写「已复核」**。
   - 脚本输出带「⚠️ 近似值」时（如节气超出 1900–2052 表范围），须如实告知精度受限。
   - 改动脚本后必须跑三道校验（`_selftest.py` / `_tools/audit_vs_doc.py` / `_tools/audit_commands.py`），三个都要绿。
7. **算法准确性**：
   - 排盘/装卦口径一律以 `references/08-algorithms.md` 为准；
   - **不凭记忆写固定表格**（骨重表、星曜对冲表、纳音表等），必须查脚本、工具或原表；
   - 案例若给出具体日期就必须排对，不许用「假设」掩盖矛盾数据；
   - 无法运行脚本时如实写「手算未复核」，**不得虚报已复核**；
   - 流派分歧（子时换日、五格外格、奇门定局、玄空排法）须明说。
