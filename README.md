# zhonghua-shushu · 中华传统占卜术数 Skill

一个面向 AI 智能体的**中华传统术数领域技能包**：覆盖命理、占卜、相术风水、择日起名等 20 余种术数的知识讲解、排盘起卦实操、场景选型、案例教学与模板套用，并内置严格的理性边界与反诈骗条款。

> **定位**：懂古典术数，也懂现代理性边界的传统文化顾问。
> **重要声明**：本仓库内容属**传统文化与民俗研究**范畴，仅供文化学习、娱乐与参考，**不构成**医疗、法律、投资、婚姻、生育等任何重大决策依据。

---

## 一、这个 Skill 能做什么

| 能力 | 说明 |
| --- | --- |
| 知识讲解 | 20+ 种术数的起源、原理、术语白话解释、流派争议标注 |
| 排盘起卦 | 八字四柱、大运起运、六爻装卦（纳甲/世应/六亲）、梅花起卦体用、紫微安星、择日、五格姓名 |
| 场景选型 | 决策树 + 场景推荐表：问一事用卦占，问一生用命理，问环境用风水，问日子用择日 |
| 案例教学 | 每术一条完整虚构推理链，数据均经核算 |
| 模板套用 | 八字简批、断卦、择日、风水、起名等可直接套用的输出骨架 |
| 避坑指南 | 常见骗局识别 + 拒绝话术（拒绝宿命论恐吓与收费改运敛财） |

覆盖术数：四柱八字、紫微斗数、铁板神数、称骨、达摩一掌经、鬼谷子两头钳、六爻纳甲、梅花易数、周易卦爻辞、大六壬、奇门遁甲、太乙神数、文王课/金钱课、面相、手相、风水堪舆、姓名学、测字、择日、果老星宗/七政四余、米卦/鸟卦/扶乩/抽签等民俗占法。

## 三、安装与使用

### 安装

将本仓库整个目录放入技能目录即可：

- **用户级**（对所有项目生效）：`~/.workbuddy/skills/zhonghua-shushu/`
- **项目级**（仅当前项目生效）：`{workspace}/.workbuddy/skills/zhonghua-shushu/`

```bash
# 用户级安装示例
git clone https://github.com/AsuraYY/zhonghua-shushu.git \
  ~/.workbuddy/skills/zhonghua-shushu
```

### 触发方式

在对话中提到下列任一内容即可自动触发：

`八字` / `子平` / `紫微` / `斗数` / `六爻` / `纳甲` / `梅花易` / `周易` / `六壬` / `奇门遁甲` / `太乙` / `称骨` / `一掌经` / `风水` / `堪舆` / `玄空` / `八宅` / `择日` / `黄历` / `姓名学` / `测字` / `面相` / `手相` / `果老星宗` / `七政四余`

或提出这类问题：

- 「该用哪种术数看这件事？」
- 「帮我排个八字 / 起一卦」
- 「这个命盘 / 这卦怎么看？」
- 「下周搬家哪天日子好？」

### 按需加载

`SKILL.md` 是入口，实操细节拆在 `references/` 中，**只加载当前问题需要的章节**，避免上下文浪费。

## 四、硬性规则（使用本 Skill 时必须遵守）

1. **边界声明**：每次解读前后都声明「传统文化与民俗参考，不构成重大决策依据」。
2. **禁止**：宿命论恐吓、伪科学断言、收费改运/开光/消灾敛财话术、鼓励沉迷或频繁占问。
3. **健康/心理/安全**议题一律建议就医或寻求专业帮助，术数不能替代诊疗。
4. **隐私**：不索取、不复述真实第三方隐私；案例一律虚构。
5. **传承争议要标注**（如铁板神数、梅花易数托名问题），不冒充「唯一正统」。
6. **算法准确性**：
   - 排盘/装卦一律以 `references/08-algorithms.md` 为准，**手算必须用万年历或排盘库复核**；
   - **不凭记忆写固定表格**（骨重表、星曜对冲表、纳音表等），必须查工具或原表；
   - 案例若给出具体日期就必须排对，不许用「假设」掩盖矛盾数据；
   - 凡声明「已复核」须写明所用工具/脚本与结果，无法运行工具时如实写「手算未复核」；
   - 流派分歧（子时换日、五格外格、奇门定局、玄空排法）须明说。
