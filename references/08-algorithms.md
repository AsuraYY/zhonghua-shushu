## A. 八字排盘

### A1. 年柱
以**立春**为界（非农历正月初一）。立春前出生用上一年干支。
> 例：1990 年立春为 2 月 4 日 → 1990-04-12 出生属**庚午**年。

### A2. 月柱（地支 + 天干）

| 月 | 地支 | 起始节 |
| --- | --- | --- |
| 正月 | 寅 | 立春 |
| 二月 | 卯 | 惊蛰 |
| 三月 | 辰 | 清明 |
| 四月 | 巳 | 立夏 |
| 五月 | 午 | 芒种 |
| 六月 | 未 | 小暑 |

| 八月 | 酉 | 白露 |
| 九月 | 戌 | 寒露 |
| 十月 | 亥 | 立冬 |
| 十一月 | 子 | 大雪 |
| 十二月 | 丑 | 小寒 |

**天干由「五虎遁」（年上起月）定**：

> 甲己之年丙作首，乙庚之岁戊为头，
> 丙辛必定寻庚起，丁壬壬位顺行流，
> 戊癸何方发，甲寅之上好追求。

| 年干 | 正月（寅月）起 |
| --- | --- |
| 甲、己 | 丙寅 |
| 乙、庚 | 戊寅 |
| 丙、辛 | 庚寅 |
| 丁、壬 | 壬寅 |
| 戊、癸 | 甲寅 |

再按月序顺推。
> 实测：1990 庚午年（庚）→ 寅月戊寅、卯月己卯、**辰月庚辰**。1990-04-12 在清明后立夏前 → 月柱**庚辰** ✓

### A3. 日柱
优先查万年历或排盘库。手算用**儒略日（JDN）法**（已用 1949-10-01=甲子日、2000-01-01=戊午日、2024-02-10=甲辰日三点交叉校验通过）：

```
a = (14 - 月) // 12
Y = 年 + 4800 - a
M = 月 + 12*a - 3
JDN = 日 + (153*M + 2)//5 + 365*Y + Y//4 - Y//100 + Y//400 - 32045

锚点：JDN(2000-01-07) = 甲子日（序号 0）
序号 = (JDN - JDN(2000-01-07)) mod 60
天干 = 序号 mod 10（0=甲）；地支 = 序号 mod 12（0=子）
```
> 实测：1990-04-12 → **丁未** ✓

⚠️ 边界（易漏）：① 公式仅适用**格里高利历**（现行公历），1582-10-15 之前的历史日期因历法不同不可直接套用；② 若真太阳时校正后时间跨过 24:00，**先按校正结果推移日期、再代入公式**（先校正、再定日柱），否则晚子时附近会错一日。

### A4. 时柱
**地支按时辰：** 子 23–1、丑 1–3、寅 3–5、卯 5–7、辰 7–9、巳 9–11、午 11–13、未 13–15、申 15–17、酉 17–19、戌 19–21、亥 21–23。

**天干由「五鼠遁」（日上起时）定：**

> 甲己还加甲，乙庚丙作初，
> 丙辛从戊起，丁壬庚子居，
> 戊癸何方发，壬子是真途。

| 日干 | 子时起 |
| --- | --- |
| 甲、己 | 甲子 |
| 乙、庚 | 丙子 |
| 丙、辛 | 戊子 |
| 丁、壬 | 庚子 |
| 戊、癸 | 壬子 |

> 实测：丁未日（丁）→ 子庚子、丑辛丑、寅壬寅、卯癸卯、辰甲辰、**巳乙巳**。10:30 属巳时 → 时柱**乙巳** ✓

**子时换日争议**：23:00–24:00 为「夜子时」，多数现代排盘按次日计（日柱顺延），亦有流派当日计。须全程统一并注明。

### A5. 真太阳时（出生地校正）
北京时间以东经 **120°** 为基准：

```
真太阳时 = 北京时间 + (当地经度 − 120°) × 4 分钟 + 均时差
```
- 经度每差 1° = 4 分钟；东经大于 120° 加、小于 120° 减。
- 均时差逐日不同（约 ±16 分钟），需查表或用天文算法，不可忽略。
> 实测（虚构人物）：兰州 103.83°E，(103.83−120)×4 = −64.7 分；5 月中旬某日均时差约 +3.7 分 → 北京时间 14:50 校正为 14:50 − 64.7 分 + 3.7 分 ≈ **13:49** ✓

跨时区出生须先换算为当地平太阳时再校正。

### A6. 起大运（两步：定顺逆 → 算天数）

**第一步：定顺逆**（"阴阳"指**年干**阴阳，非日主）：
- 阳年干（甲丙戊庚壬）男命 / 阴年干（乙丁己辛癸）女命 → **顺排**，顺数到下一个「节」
- 阴年干男命 / 阳年干女命 → **逆排**，逆数到上一个「节」

**第二步：折算起运岁数**
> **三天折一岁**，一日折四月，一个时辰折十天。

```
起运岁数 = 出生时刻到该「节」的天数 ÷ 3
起运月数 = 天数 × 4        （一日折四月）
```
注意是「**节**」不是「中气」——用错会差整整一节。

**取整口径（脚本与本文统一）**：按「已满」的整月数**向下取整**（3.9 月记 3 月，不四舍五入）。
> 实测校准两例：
> - 1990-04-12（庚午年，庚=阳）：男顺数至立夏 23.68 天 → 94.7 月 → **7 岁 10 月**；女逆数至清明 7.04 天 → 28.2 月 → **2 岁 4 月** ✓
> - 2001-04-08 06:00（辛巳年，辛=阴，虚构示例）：男逆数至清明（4-05 01:12）3.19 天 → 12.8 月 → **1 岁 0 月**（若按四舍五入则作 1 岁 1 月，差别仅在取整方式）

⚠️ **起运岁数在 0–10 岁全域分布，没有默认值，必须实算。** 抽样实测（生辰 × 性别共 14 组）落在 0岁7月 / 1岁5月 / 2岁4月 / 4岁8月 / 5岁2月 / 7岁3月 / 8岁2月 / 9岁9月 等各处。

### A9. 空亡
以日柱（或年柱，流派不同）所在旬查，该旬中缺的两个地支为空亡。
- 旬 = 十天干配十二地支，每旬 10 组，余 2 支不入。
> 例：甲辰旬（甲辰、乙巳…癸丑）空**寅卯**；甲午旬（甲午、乙未…癸卯）空**辰巳**；甲申旬空**午未**。

六爻则以**起卦日**干支查旬空，与八字查法不混用。

## C. 梅花易数起卦

> 🔧 **别手起**：直接跑 `python3 scripts/meihua.py --numbers 3,8`
> （时间起卦：`--time "2026-10-16 14:00" --lunar-month 8 --lunar-day 24`；
> 脚本不支持公历⇄农历换算，农历月日须由使用者给出）。

### C1. 先天八卦数（起卦必用）
乾1、**兑2**、**离3**、震4、**巽5**、**坎6**、艮7、**坤8**

### C2. 数字起卦
```
上卦 = 数1 mod 8   （余 0 作 8）
下卦 = 数2 mod 8
动爻 = (数1 + 数2) mod 6   （余 0 作第 6 爻动）
```

### C3. 时间起卦（农历）
```
上卦 = (年支序数 + 月 + 日) mod 8
下卦 = (年支序数 + 月 + 日 + 时支序数) mod 8
动爻 = (年支序数 + 月 + 日 + 时支序数) mod 6
```
年支序数：子1 丑2 寅3 卯4 辰5 巳6 午7 未8 申9 酉10 戌11 亥12；
时支序数：子1…亥12。余 0 按除数计（即 8 或 6）。

### C4. 体用判定（关键规则）
> **动爻所在的那个卦 = 用卦；另一个（无动爻的）卦 = 体卦。**

即动爻在下卦 → 下卦为用、上卦为体；动爻在上卦（四/五/上爻）→ 上卦为用、下卦为体。**不可凭"上卦就是体"想当然。**

### C5. 体用生克含义（五行：木火土金水顺生、隔位克）
| 关系 | 含义 |
| --- | --- |
| 体用比和（同五行） | 事易顺 |
| **用生体** | 事来就我，吉 |
| **体克用** | 我能控事，需努力 |
| **体生用** | 我泄气，付出多 |
| **用克体** | 事压我，费力、阻滞 |

⚠️ 常见错误：把"体离火 + 用坎水"判成"体克用"。水克火，正确为**用克体**。判定前先确认"谁克谁"；八卦五行对照见第 0 节。

### C6. 八卦方位（后天八卦，寻物/方位常用）
| 卦 | 方位 | 卦 | 方位 |
| --- | --- | --- | --- |
| 坎 | 北 | 离 | **南** |
| 艮 | 东北 | 坤 | 西南 |
| 震 | 东 | 兑 | 西 |
| 巽 | **东南** | 乾 | 西北 |

⚠️ 起卦数用先天、断方位用后天，两套不要混用（先天八卦方位为：乾南、坤北、离东、**坎西**、震东北、兑东南、巽西南、艮西北，与上表不同——注意先天正北是坤、正西是坎）。

### C7. 互卦与变卦
- **互卦**（过程）：二三四爻组成下卦，三四五爻组成上卦
- **变卦**（结果）：动爻阴阳互变后所得之卦

## D. 紫微斗数安星（铁律与警示）

- 十四主星：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军。
- 紫微系六星逆布，天府系八星顺布；**天府的对宫恒为七杀**（可用来校验排盘是否排错）。
- ⚠️ **命宫与迁移宫（对宫）的星曜组合由安星表决定，不可凭印象编造。** 例如"命宫天机 + 迁移宫天梁"并非恒不成立——天机与天梁的关系随紫微落宫而变：紫微在巳/亥 → 二者同宫于辰/戌；紫微在寅/申 → 二者对冲于丑/未（此时该组合成立）；其余八种为三合或相隔。凡涉及宫位星曜，一律按生辰实排后引用。
- 三方四正 = 本宫 + 对宫 + 两个三合宫，共四宫。天梁出现在命宫的三方四正之内是常见的，但落在哪宫须实排。
- 四化依生年天干起（如壬年：天梁化禄、紫微化权、左辅化科、武曲化忌）。

## G. 五格剖象（仅参考，近现代产物）
> 🔧 可用脚本：`python3 scripts/wuge.py --surname-strokes 11 --given-strokes 8,7`
> （笔画**须由使用者按繁体/康熙字典**提供，脚本不内置笔画库）。
> 脚本同时给出外格的两种常见算法，并**不输出 81 数理吉凶**。
- **笔画以繁体（康熙字典）为准**，简体笔画会得出完全不同结果；特殊部首（如"氵"计水 4 画、"忄"计心 4 画）须按部首原字计。
- 天格：单姓 = 姓笔画 + 1；复姓 = 各字之和
- 人格：姓末字 + 名首字
- 地格：单名 = 该字 + 1；复名 = 各字之和
- 总格：姓名全部字笔画之和
- 外格：**算法各派不一**（常见取"总格 − 人格"，单姓单名另有"假成 1+1 = 2"之规），存在分歧，不宜据此下判断。
- 81 数理吉凶表为固定附会，无预测效力，仅作文化参考。
