# 分章二：占卜问事类

> 边界：问事占卜属民俗参考，一事一占、结果不绝对；涉及健康/法律/投资请找专业人士。案例均虚构。
> **起卦与装卦算法见 [08-algorithms.md](08-algorithms.md) B、C 节**（铜钱爻象、纳甲、八宫卦序、世应、六亲、梅花起卦与体用判定）。

## 5. 六爻（纳甲筮法）

### 原理
用三枚铜钱（或工具）摇六次得六爻卦，将干支「纳」入爻中，安世应、六亲，以**用神**为中心看生旺墓绝、空破、动变，判断事情成败、快慢、助力阻力与**应期**（应验时间）。

### 术语表

| 术语 | 白话 |
| --- | --- |
| 起卦 | 摇出卦象 |
| 本卦 / 变卦 | 原始卦 / 动爻变化后的卦 |
| 纳甲 | 给爻配上天干地支（八宫各有固定纳法） |
| 世爻 / 应爻 | 我方 / 对方或目标方，二者恒隔三位 |
| 六亲 | 父母（文书、长辈）、兄弟、子孙（福神）、妻财、官鬼（事业、压力、官非），以卦宫五行为「我」推定 |
| 用神 | 代表所问之事的那一爻 |
| 原神 / 忌神 | 生用神者 / 克用神者（另有仇神：克原神、生忌神者） |
| 月建、日辰 | 月支、日支，决定旺衰 |
| 空亡 | 旬空（以**起卦日**干支查），暂时无气、落空 |
| 月破 | 爻被月支冲，无用或出月可用 |
| 动爻 / 变爻 | 发动之爻及其变出之爻 |
| 应期 | 事应验的时间点（填实、冲空、出月、逢值等） |

### 操作流程

1. **定占题**：一句话写清问什么、涉及谁、时限（如「本月内能否入职 A 公司」）。
2. **起卦**：三枚同硬币，默念占题，摇六次，**自下而上**记录。爻象规则见 [08](08-algorithms.md) B1（三背 = 老阳○、三字 = 老阴×、一背二字 = 少阳「单」、二背一字 = 少阴「拆」；另有流派以字为阳，选定后不改）。
3. **装卦**：纳干支（B2）、定卦宫（B3）、安世应（B4）、排六亲（B5）。
4. **取用神**：问财取妻财，问工作/考试取官鬼或父母（视具体：古代功名取官鬼，现代考试多取父母为文书成绩），问孩子/解忧取子孙，问对象（男问）取妻财等。
5. **断旺衰**：用神与世爻得月建日辰生扶否？动爻生克如何？空破墓绝？
6. **断过程**：动爻多则事体复杂；变生变克看趋势。
7. **断应期**：常见：应期在用神旺相之月/日、冲空之日、变爻填实之期。
8. **写行动建议**：能推进的条件、需避免的做法。
9. **边界声明**。

> ⚠️ 断卦以**用神旺衰与生克**为主，不以卦名吉凶下判断（如"既济=事成"属附会，不作依据）。

### 一事一占规则
- 同一事不反复摇到「满意」。
- 已有明确盘面则以第一次为准。
- 不代人秘密占断其隐私细节。

### 案例（虚构，卦名与装卦要素已逐步核对）
- **占题**：「下月能否顺利签下某培训课程报名的优惠名额（小决策，虚构）。」
- **起卦示意**：本卦「**水雷屯**」（坎上震下）变「**风雷益**」（巽上震下）。
- **装卦**（屯属**坎宫二世卦**，坎宫属水；纳干：内三爻庚、外三爻戊）：

| 爻 | 爻性 | 纳支 | 六亲 | 备注 |
| --- | --- | --- | --- | --- |
| 上六 | 阴→阳（动） | 戊子（水） | **兄弟** | 动爻，变出卯木 |
| 九五 | 阳 | 戊戌（土） | 官鬼 | **应爻** |
| 六四 | 阴 | 戊申（金） | **父母** | **用神** |
| 六三 | 阴 | 庚辰（土） | 官鬼 | |
| 六二 | 阴 | 庚寅（木） | 子孙 | **世爻** |
| 初九 | 阳 | 庚子（水） | 兄弟 | |

  - 校验：坎（阴、阳、阴）变巽（阴、阳、阳）需上爻由阴转阳 → **上爻动**，变卦为益 ✓；世在二、应在五（隔三位）✓；内卦震纳庚（子寅辰）、外卦坎纳戊（申戌子） ✓（纳甲按本卦内外经卦装，不按卦宫）。
- **用神**：问消费文书，取**父母爻（申金，四爻，静）**为用；世爻为求测人。
- **推理**：
  1. 用神父母申金安静 → 文书本就存在、流程本身不折腾。
  2. **兄弟爻（上爻）独发** → 主竞争、破耗：名额有人抢，或报名费之外另有加价。
  3. 世持子孙寅木，且寅与用神申金相冲 → 变数主要在求测人自己的时间安排与犹豫，宜早提交、别拖到最后。
- **断**：可成，但宜早申请、盯紧条款与附加费用；应期参考兄弟爻动化卯木，逢合之日（戌日合卯）前后落地。
- **建议**：看清楚退费条款再付。
- **边界**：「这是卦象结构推演，不构成消费合同意见。」

### 经典书目
《增删卜易》《卜筮正宗》《易冒》《易隐》（择一深耕）

## 6. 梅花易数

### 原理
万物皆可起卦：年月日时、数字、笔画、所见物象、声音。得上卦、下卦、动爻，分**体卦**（自己/主方）与**用卦**（事/对方），看五行生克与卦象含义直断。

### 术语

| 术语 | 白话 |
| --- | --- |
| 体卦 | **无动爻的那个卦**（代表我方） |
| 用卦 | **动爻所在的那个卦**（代表所问之事/对方） |
| 体用比和 | 体用五行相同，事易顺 |
| 用生体 | 事来就我，吉 |
| 体克用 | 我能控事，需努力 |
| 用克体 | 事压我，费力、阻滞 |
| 体生用 | 我泄气，付出多 |
| 卦象 | 如离为火/文书，坎为水/险，巽为风/文书进退，艮为山/止 |

> ⚠️ 体用不是"上卦即体"。**动爻在哪个卦，哪个卦就是用卦。**

### 起卦方法
1. **时间起卦**（农历）：上卦 =(年支序+月+日) mod 8；下卦 =(年支序+月+日+时支序) mod 8；动爻 = 四数之和 mod 6。余 0 按除数计。
2. **数字起卦**：上卦 = 数1 mod 8，下卦 = 数2 mod 8，动爻 =(数1+数2) mod 6。
3. **物象起卦**：见物可分内下外上、动静定动爻。
4. **字占**：总笔画或偏旁拆分。

**先天八卦数（必背）**：乾1 兑2 离3 震4 巽5 坎6 艮7 坤8。
⚠️ 易错点：**5 = 巽、6 = 坎**，二者不要记反。

### 解读步骤
1. 写出体用卦与五行（先确认动爻位置）。
2. 先看体用生克（主基调），判定时确认"谁克谁"。
3. 再读卦象与爻辞意象（补细节）。
4. 看互卦（过程）、变卦（结果）。
5. 给一句结论 + 一个条件 + 边界。

### 案例（虚构·起卦与体用已逐步核算）
- **情景**：虚构「丢失一支笔，问能否找回」。
- **起卦**：报数 **3、8**（虚构）。
  - 上卦 = 3 → **离**；下卦 = 8 → **坤**；动爻 =(3+8) mod 6 = **5**，即五爻，**落在上卦**。
  - 得本卦「**火地晋**」（离上坤下）。
- **体用**：动爻在**上卦** → 上卦离为**用卦**，下卦坤为**体卦**。体 = 坤（土），用 = 离（火）。
  - 判定：**火生土 → 用生体**（事来就我，吉），不是"体克用"。
- **互卦（过程）**：二三四爻 = 阴阴阳 = 艮；三四五爻 = 阴阳阴 = 坎 → **水山蹇**（坎上艮下），含艮（桌柜、止）、坎（暗处、陷）。
- **变卦（结果）**：五爻动，上卦离（阳、阴、阳）中爻转阳 → 乾，得 **天地否**（乾上坤下）。
- **断**：用生体（火生土）→ 事来就我，物未远去；变卦为否提示过程有阻滞，但不据此翻案——**不以卦名断吉凶**；坤为地/方/容器，艮为桌柜，坎为暗处 → 往**西南方位**的桌柜、容器或光线偏暗处找；两日内概率最高。
- **边界**：「象数联想，不保证结果。方位取法各派有别，仅作线索。」

### 经典书目
《梅花易数》《邵康节先生梅花数》相关整理本（均属托名/层累之作，宜批判阅读）

## 7. 周易本卦变卦（卦爻辞）

### 原理
通过蓍草法、数字法或摇卦得一卦（六爻），读卦名、卦辞、爻辞、象传，偏**义理与处境启发**，不是精细时间预测术。

### 操作要点
1. 得本卦与变爻 → 变卦。
2. 读卦名与卦辞总义。
3. 读动爻爻辞（有时看本卦与变卦两辞）。
4. 翻译成现代处境语言，避免神学腔。

### 案例（虚构）
- **得卦**：「谦」卦。
- **解读**：主旨是谦退有终、地中有山；问合作则宜让利、留名声给对方。
- **边界**：「爻辞是古典哲学文本，不是命运判决。」

### 经典书目
《周易》经传、《易传》十翼选读

## 8. 大六壬

### 原理
三式之一（太乙、奇门、六壬）。以**月将加时**立天地盘，发四课、三传，配十二天将与类神，断事细腻。

### 术语
- **月将**：太阳过宫的将神，按**节气**（非农历月）更换。
- **四课**：一课为日干上神，二课为干上之阴神，三课为日支上神，四课为支上之阴神。
- **三传**：初传（发端）、中传（中程）、末传（结果）。
- **十二天将**：贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后。
- **类神**：代表所问之人的神将（如问官看青龙/贵人等）。

### 学习注意
术语密度极高；月将起例、课传排法**须用排盘工具**（各派起例有出入，本技能不内置课式表）。若用户只是好奇，给文化说明与示意课例即可，不假装精断。

### 经典书目
《大六壬指南》《六壬大全》《壬归》

## 9. 奇门遁甲

### 原理（时家奇门）
按时辰排局：九宫、三奇（乙丙丁）、六仪（戊己庚辛壬癸）、八门、九星、八神，看**用神落宫**与门星神组合，用于策略、择时、事情格局。

### 术语
| 术语 | 白话 |
| --- | --- |
| 九宫 | 洛书九宫格，时空坐标 |
| 八门 | 休、生、伤、杜、景、死、惊、开 |
| 九星 | 天蓬、天芮、天冲、天辅、天禽、天心、天柱、天任、天英 |
| 八神 | 值符、螣蛇、太阴、六合、白虎、玄武、九地、九天 |
| 值符 / 值使 | 当班星/门，统领 |
| 用神 | 人、事对应的宫（如问求人看年命/日干落宫） |
| 空亡、入墓 | 落空、无力 |

> ⚠️ 定局涉及超神接气、置闰/拆补之争，**必须用排盘工具**，不手排。

### 解读框架
1. 定用神宫与值使门。
2. 看旺衰、迫制、门星神。
3. 看日干/时干关系（主客）。
4. 给策略建议（进攻、等待、借力、换时）。
5. 边界声明。

### 案例（虚构）
- **问**：「本月是否适合公开发布个人作品集（虚构）。」
- **示意**：开门 + 天辅落宫旺，日干得生。
- **断**：发布可行，宜白天、宜正式平台；避免与人争着同期对撞。
- **边界**：「时机建议，不保证市场成功。」

### 经典书目
《遁甲符应经》《奇门遁甲》古籍整理、现代教材（择一）

## 10. 太乙神数（简述）

三式之一，主大势、年景、国运与长期格局，排式复杂，民用极少；古籍多托名，成书年代有争议。作文化介绍：与六壬（人事细断）、奇门（时空策略）并称三式。不用于个人消费级营销。

## 11. 文王课 / 金钱课 / 签占

### 原理
民间摇卦、抽签，配固定签诗或断语（上上、中平、下下等）。
### 用法
- 简单摇卦可对照六爻简化或签文主题。
- 解释签文时翻译成处境建议，**拒绝**用下下签恐吓。
- 明确民俗娱乐向。

### 案例（虚构）
- **抽得**：中签，诗云「云开月出见分明」（虚构）。
- **解**：事情有反复，但中段转明；宜守时待机，勿强求立刻结果。
- **边界**：「签诗是文学比喻，不是预言书。」
