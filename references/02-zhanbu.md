# 分章二：占卜问事类

> 边界：问事占卜属民俗参考，一事一占、结果不绝对；涉及健康/法律/投资请找专业人士。案例均虚构。

## 5. 六爻（纳甲筮法）

### 原理
用三枚铜钱（或工具）摇六次得六爻卦，将干支「纳」入爻中，安世应、六亲，以**用神**为中心看生旺墓绝、空破、动变，判断事情成败、快慢、助力阻力与**应期**（应验时间）。

### 术语表

| 术语 | 白话 |
| --- | --- |
| 起卦 | 摇出卦象 |
| 本卦 / 变卦 | 原始卦 / 动爻变化后的卦 |
| 纳甲 | 给爻配上天干地支 |
| 世爻 / 应爻 | 我方 / 对方或目标方 |
| 六亲 | 父母（文书、长辈）、兄弟、子孙（福神）、妻财、官鬼（事业、压力、官非） |
| 用神 | 代表所问之事的那一爻 |
| 原神 / 忌神 | 生用神者 / 克用神者 |
| 月建、日辰 | 月支、日支，决定旺衰 |
| 空亡 | 旬空，暂时无气、落空 |
| 月破 | 爻被月支冲，无用或出月可用 |
| 动爻 / 变爻 | 发动之爻及其变出之爻 |
| 应期 | 事应验的时间点（填实、冲空、出月、逢值等） |

### 操作流程

1. **定占题**：一句话写清问什么、涉及谁、时限（如「本月内能否入职 A 公司」）。  
2. **起卦**：三枚同硬币，默念占题，摇六次，记录背/字（老阳、少阳、少阴、老阴）。从下爻装到上爻。  
3. **装卦**：纳干支、定世应、安六亲。  
4. **取用神**：问财取妻财，问工作/考试取官鬼或父母（视具体），问孩子/解忧取子孙，问对象（男问）取妻财等。  
5. **断旺衰**：用神与世爻得月建日辰生扶否？动爻生克如何？空破墓绝？  
6. **断过程**：动爻多则事体复杂；变生变克看趋势。  
7. **断应期**：常见：应期在用神旺相之月/日、冲空之日、变爻填实之期。  
8. **写行动建议**：能推进的条件、需避免的做法。  
9. **边界声明**。

### 一事一占规则
- 同一事不反复摇到「满意」。  
- 已有明确盘面则以第一次为准。  
- 不代人秘密占断其隐私细节。

### 案例（虚构）
- **占题**：「下月能否顺利签下某培训课程报名的优惠名额（小决策，虚构）。」  
- **起卦示意**：得卦「水雷屯」变「风雷益」（示意）。  
- **用神**：问消费文书，取**父母爻**为用；世爻为求测人。  
- **推理**：父母爻得日辰生扶但动而化退，表示名额文书会来但有反复；世爻临兄弟，主竞争。  
- **断**：可成，但需早定、防条款变化；应期在申酉日补齐文书。  
- **建议**：看清楚退费条款再付。  
- **边界**：「这是卦象结构推演，不构成消费合同意见。」

### 经典书目
《增删卜易》《卜筮正宗》《易冒》《易隐》（择一深耕）

## 6. 梅花易数

### 原理
万物皆可起卦：年月日时、数字、笔画、所见物象、声音。得上卦、下卦、动爻，分**体卦**（自己/主方）与**用卦**（事/对方），看五行生克与卦象含义直断。

### 术语

| 术语 | 白话 |
| --- | --- |
| 体卦 | 代表我方的卦 |
| 用卦 | 代表所问之事的卦 |
| 体用比和 | 体用五行相同，事易顺 |
| 用生体 | 事来就我，吉 |
| 体克用 | 我能控事，需努力 |
| 用克体 | 事压我，费力 |
| 体生用 | 我泄气，付出多 |
| 卦象 | 如离为火/文书，坎为水/险，巽为风/文书进退，艮为山/止 |

### 起卦方法
1. **时间起卦**：农历年支数+月+日为上卦，年+月+日+时为下卦，总和除 6 取动爻。  
2. **数字起卦**：两组数分作上下卦（除 8 取余），和除 6 取动爻。  
3. **物象起卦**：见物可分内下外上、动静定动爻。  
4. **字占**：总笔画或偏旁拆分。

### 解读步骤
1. 写出体用卦与五行。  
2. 先看体用生克（主基调）。  
3. 再读卦象与爻辞意象（补细节）。  
4. 看互卦（过程）、变卦（结果）。  
5. 给一句结论 + 一个条件 + 边界。

### 案例（虚构）
- **情景**：用户丢失一支笔，问能否找回（小物）。  
- **起卦**：以报数「3、5」示意，得离上坎下？此处示意为体卦离火、用卦坎水。  
- **推理**：体克用，我方能去找；坎为水为暗处，离为光明为东南方。  
- **断**：大概率在光线一般、近水或低处；两日内可寻。  
- **边界**：「物象联想，不保证结果。」

### 经典书目
《梅花易数》《邵康节先生梅花数》相关整理本

## 7. 周易本卦变卦（卦爻辞）

### 原理
通过蓍草法、数字法或摇卦得一卦（六爻），读卦名、卦辞、爻辞、象传，偏**义理与处境启发**，不是精细时间预测术。

### 操作要点
1. 得本卦与变爻 → 变卦。  
2. 读卦名与卦辞总义。  
3. 读动爻爻辞（有时看本卦与变卦两辞）。  
4. 翻译成现代处境语言，避免神学腔。

### 案例（虚构）
- **得卦**：「谦」卦。  
- **解读**：主旨是谦退有终、地中有山；问合作则宜让利、留名声给对方。  
- **边界**：「爻辞是古典哲学文本，不是命运判决。」

### 经典书目
《周易》经传、《易传》十翼选读

## 8. 大六壬

### 原理
三式之一（太乙、奇门、六壬）。以月将加时立天地盘，发四课、三传，配十二天将与类神，断事细腻。

### 术语
- **月将**：太阳过宫的将神。  
- **四课**：干支与天地盘关系的四课。  
- **三传**：初传（发端）、中传（中程）、末传（结果）。  
- **十二天将**：贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后。  
- **类神**：代表所问之人的神将（如问官看青龙/贵人等）。

### 学习注意
术语密度极高；若用户只是好奇，给文化说明与示意课例即可，不假装精断。

### 经典书目
《大六壬指南》《六壬大全》《壬归》

## 9. 奇门遁甲

### 原理（时家奇门）
按时辰排局：九宫、三奇（乙丙丁）、六仪（戊己庚辛壬癸）、八门、九星、八神，看**用神落宫**与门星神组合，用于策略、择时、事情格局。

### 术语
| 术语 | 白话 |
| --- | --- |
| 九宫 | 洛书九宫格，时空坐标 |
| 八门 | 休、生、伤、杜、景、死、惊、开 |
| 九星 | 天蓬、天芮、天冲、天辅、天禽、天心、天柱、天任、天英 |
| 八神 | 值符、螣蛇、太阴、六合、白虎、玄武、九地、九天 |
| 值符 / 值使 | 当班星/门，统领 |
| 用神 | 人、事对应的宫（如问求人看年命/日干落宫） |
| 空亡、入墓 | 落空、无力 |

### 解读框架
1. 定用神宫与值使门。  
2. 看旺衰、迫制、门星神。  
3. 看日干/时干关系（主客）。  
4. 给策略建议（进攻、等待、借力、换时）。  
5. 边界声明。

### 案例（虚构）
- **问**：「本月是否适合公开发布个人作品集（虚构）。」  
- **示意**：开门+天辅落宫旺，日干得生。  
- **断**：发布可行，宜白天、宜正式平台；避免与人争着同期对撞。  
- **边界**：「时机建议，不保证市场成功。」

### 经典书目
《遁甲符应经》《奇门遁甲》古籍整理、现代教材（择一）

## 10. 太乙神数（简述）

三式之一，主大势、年景、国运与长期格局，排式复杂，民用极少。作文化介绍：与六壬（人事细断）、奇门（时空策略）并称三式。不用于个人消费级营销。

---

## 11. 文王课 / 金钱课 / 签占

### 原理
民间摇卦、抽签，配固定签诗或断语（上上、中平、下下等）。  
### 用法
- 简单摇卦可对照六爻简化或签文主题。  
- 解释签文时翻译成处境建议，**拒绝**用下下签恐吓。  
- 明确民俗娱乐向。

### 案例（虚构）
- **抽得**：中签，诗云「云开月出见分明」（虚构）。  
- **解**：事情有反复，但中段转明；宜守时待机，勿强求立刻结果。  
- **边界**：「签诗是文学比喻，不是预言书。」
