# 分章三：相术与环境类

> 边界：相术只谈气质与状态观察，不给人贴宿命标签；风水优先宜居与安全；姓名学是参考不是判决。案例均虚构。

## 12. 面相

### 原理
通过五官、三停、十二宫、骨相与气色，观察健康状态、气质类型与当下精神面貌。传统相术有「相随心转」之说，与现代行为观察可并存——**人的选择与修养会改变气质**。

### 术语

| 术语 | 白话 |
| --- | --- |
| 三停 | 上停（发际至眉，早年/思维）、中停（眉至鼻，中年/执行）、下停（鼻至下巴，晚年/承载） |
| 十二宫 | 命宫（印堂）、财帛、官禄、夫妻、子女、迁移、疾厄、父母、兄弟、仆役、田宅、福德 |
| 五官 | 眉（保寿）、眼（监察）、耳（采听）、鼻（审辨）、口（出纳） |
| 气色 | 面部光泽与色调，反映休息、情绪、健康（非诊断） |

### 解读框架
1. 整体气质（沉稳/外放/急躁…）  
2. 三停比例与平衡（象征叙事，不绝对）  
3. 用户关心的宫位（如问合作看奴仆/迁移）  
4. 气色与作息提醒（睡眠、压力）  
5. 声明：观察≠诊断，相不独论  

### 案例（虚构）
- **观察**：虚构「陈可」眉清、眼有神、鼻梁直、唇角平。  
- **解读**：气质偏理性务实，表达直接；中停强，执行阶段佳。  
- **建议**：合作时把情感需求说清楚，避免对方误以为冷淡。  
- **边界**：「外貌不能决定人品与能力，以行为为准。」

### 书目
《麻衣神相》《柳庄相法》《神相全编》（作文化读物）

## 13. 手相

### 原理
观察手掌纹路、丘位与手型，传统分天纹（感情线）、人纹（头脑线/智慧线）、地纹（生命线）三才纹，以及金木水火土八宫丘。

### 要点
- 线纹会变；适合做「习惯与状态」叙事，不做寿命判决（**忌断生死**）。  
- 左右手法有流派差异，需说明。  

### 案例（虚构）
- **观察**：人纹长且直，地纹清晰。  
- **解读**：专注力好、恢复力叙事偏强；宜深度工作。  
- **边界**：「生命线不预测寿命，健康请体检。」

### 书目
《相理衡真》等；现代手相多为通俗读物

## 14. 风水 / 堪舆

### 原理
**形势派**：看山形水势、道路、明堂、聚气（可对应视野、通风、噪音、动线）。  
**理气派**：结合时间与方位（玄空飞星、八宅、三合等）。  
阳宅核心：门（纳气）、主（主要活动区）、灶（饮食健康）、卧（休息）、水法排污与采光。

### 术语

| 术语 | 白话 |
| --- | --- |
| 明堂 | 建筑前开阔空间，视野与活动区 |
| 藏风聚气 | 避风又不憋闷，空气流通适度 |
| 煞 | 形如尖角冲射、反弓、逼压——多为视觉压迫与安全问题 |
| 玄空飞星 | 以时间入中宫排星，看方位旺衰 |
| 八宅 | 按东四/西四命卦配门主灶方位 |
| 理气 / 形势 | 时间方位学 / 空间形态学 |

### 阳宅实操流程（宜居优先）
1. 量朝向，画平面图。  
2. 看采光、通风、潮湿、噪音、消防通道。  
3. 看动线：进门是否杂乱，卧室是否安静，厨房油烟与卫生间排污。  
4. 形势问题：尖角、反弓、高压线贴近（安全与景观）。  
5. 理气可作文化附加：飞星旺位宜书房/动区，衰位宜储物（象征性）。  
6. 给改造清单：优先低成本、高确定性（灯、帘、收纳、隔音）。  

### 阴宅简述
墓地择址属传统礼俗与地理环境选择，涉及土地法规；只作文化说明，不推销高价墓地或改运仪式。

### 案例（虚构）
- **问题**：书房总静不下心。  
- **观察**：门冲书桌、背后是窗、夜间路灯直射。  
- **建议**：桌侧移避门冲、背后加实墙/高柜、加遮光帘；再谈飞星等理气参考。  
- **边界**：「先解决采光噪音与注意力工程，再谈象征吉凶。」

### 书目
《葬书》（形势源流）、《青囊经》《阳宅十书》、玄空类教材（辨流派）

## 15. 姓名学

### 原理
综合：**音**（谐音、声调）、**形**（结构、书写）、**义**（字义、典故）、**数理**（五格剖象，近代日本传入的天人地外总格）、以及八字**喜用神**五行补益（传统思路）。

### 实操流程
1. 定姓氏与性别/家族辈分（若有）。  
2. 列出八字喜用（若用户愿意提供生日；不愿则用中性字）。  
3. 选字：意义优先、读音响亮、避免不良谐音。  
4. 五格数理仅作参考项，不单一决定。  
5. 给 2–3 个候选名与寓意，用户自选。  

### 边界
- 不说「此名必成败」。  
- 改名是个人自由，不是消灾项目。  
- 未成年人改名需法定监护人与法规程序。

### 案例（虚构）
- **姓**：沈；**补充**：喜用神示意为「木、水」。  
- **候选**：沈沐楷（水木，楷有楷模义）、沈禾雨（田园清新）。  
- **说明**：读音、避讳、家族字辈需用户确认。  

### 书目
传统避讳与诗经楚辞选名；五格剖象属近现代，不神化

## 16. 测字

### 原理
用户写一字（或指定字），用拆字、象形、加减笔、字音字义、繁简结构，结合所问之事直断。重**联想逻辑**而非死背口诀。

### 常用技法
- **拆合**：如「明」为日月，问合作则两方并明。  
- **加减笔**：「木」加一撇成「禾」，象收获。  
- **结构**：上下/左右/包围，象征处境。  
- **谐音**：补细节（谨慎，防牵强）。  
- **书写状态**：笔力轻重、歪斜（若可见）。

### 解读步骤
1. 说字形结构。  
2. 扣到问题上给 2–3 条联想。  
3. 给一句主断 + 一个条件。  
4. 声明文字游戏与文化直觉，非科学预测。

### 案例（虚构）
- **字**：「舟」；问「是否该换工作」。  
- **解读**：舟行水上，重在舵与风；换工作如换航道，需看「载具」（技能）与「风向」（行情）。  
- **断**：可换，但先考证与存粮（应急金）。  
- **边界**：「修辞启发，不是人事预言。」

### 书目
《测字秘牒》等清人笔记；现代仅作文化趣味

## 相术环境类对比

| 门类 | 看什么 | 优先用在 | 主要风险 |
| --- | --- | --- | --- |
| 面相 | 气质状态 | 初次印象、社交观察 | 外貌歧视、宿命标签 |
