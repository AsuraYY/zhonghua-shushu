# 分章九：脚本层使用手册（排盘起卦先跑脚本）

> **原则：凡是能用脚本算出来的，不许手算、不许靠记忆背表。**
> 模型负责：选口径、解释结果、说清边界；脚本负责：算出确定的数值。

## 0. 目录结构

```
scripts/
├── README.md                 脚本层说明（含数据来源与精度声明）
├── _common.py                干支/五行/纳音/十神/六亲/刑冲合害/儒略日
├── _bagua.py                 八卦 + 由八宫表推导的六十四卦 + 纳甲 + 世应
├── _astro.py                 节气查表 / 真太阳时 / 城市经度
├── _selftest.py              自检（改脚本后必跑）
├── bazi.py                   四柱八字排盘
├── liuyao.py                 六爻装卦
├── meihua.py                 梅花易数起卦
├── zeri.py                   择日/历法速查
├── wuge.py                   姓名五格
├── data/
│   └── solar_terms_1900_2052.csv   节气表（JPL DE421 预计算）
└── _tools/
    ├── gen_solar_terms.py    仅在重建数据表时使用（需 skyfield + DE421）
    ├── audit_vs_doc.py       脚本常量 vs 08-algorithms.md 表格的逐格对账
    └── audit_commands.py     文档中命令行照抄可跑性审计
```

## 1. 什么时候必须跑脚本

| 场景 | 该跑哪个 |
| --- | --- |
| 用户给了生日，要排八字 | `bazi.py` |
| 用户摇了卦/报了数，要装卦 | `liuyao.py` |
| 用户报了数/时间，要起梅花卦 | `meihua.py` |
| 问某日/某段日子的干支、冲合、建除 | `zeri.py` |
| 问名字五格 | `wuge.py` |
| 只是讲知识、讲流派、讲是非题 | 不必跑 |

**先算后解的顺序**：收齐必要参数 → 跑脚本 → **照抄脚本数值** → 按 [05 模板库](05-templates.md) 解读 → 边界声明。
脚本输出里出现「⚠️ 近似值」时，必须在回复中告知用户精度受限。

## 2. 命令速查

```bash
# 八字（推荐给出生地经度）
python3 scripts/bazi.py --datetime "1990-04-12 10:30" --gender male --lon 116.41 --years 2026,2027

# 六爻（6老阴 7少阳 8少阴 9老阳，自下而上）
python3 scripts/liuyao.py --values 7,8,7,8,7,8 --date 2026-10-16 --question-type 财

# 梅花（两数起卦）
python3 scripts/meihua.py --numbers 3,8

# 择日
python3 scripts/zeri.py --from 2026-11-01 --to 2026-11-30

# 五格（笔画需用户按繁体提供）
python3 scripts/wuge.py --surname-strokes 11 --given-strokes 8,7

# 自检
python3 scripts/_selftest.py
```

需要给缺失信息时，优先问：**出生年月日时分（注明时区）、出生地经度、性别**；
占卦则问：**起卦方式（数字/时间/卦名+动爻）、起卦日期**。

## 3. 数据精度与覆盖范围

| 项目 | 精度/覆盖 | 出处 |
| --- | --- | --- |
| 二十四节气 | 1900–2052 查 DE421 预计算表；2026 年 24 节气与公开万年历秒值最大差 34 秒 | `data/solar_terms_1900_2052.csv` + `_tools/gen_solar_terms.py` |
| 1900–2052 之外 | 退回近似公式，**脚本会打印警告**，误差可达十余分钟 | `_astro.py` |
| 日柱干支 | 精确（儒略日 + 三点交叉校验） | `_common.py` |
| 真太阳时 | 经度时差精确；均时差近似式，年较差约 ±0.6 分钟 | `_astro.py` |
| 六十四卦/世应/纳甲 | 表驱动，由八宫表推导 | `_bagua.py` |

**三层校验，改脚本后都要跑**：

| 脚本 | 校的是什么 | 项数 |
| --- | --- | --- |
| `python3 scripts/_selftest.py` | 脚本**算得对不对**（数值层）：1990-04-12 四柱与男女起运、屯之益装卦全表、火地晋梅花案例、五虎遁/五鼠遁/旬空/纳音、2026 节气秒级对照 | 48 项 |
| `python3 scripts/_tools/audit_vs_doc.py` | 脚本**与 08-algorithms.md 是否一致**（文档层）：直接从 md 解析出藏干表、纳甲表、八宫表、世应、月支表、五虎遁/五鼠遁、五行、冲合、建除、乾为天与屯卦装卦示例等，与脚本常量**逐格比对** | 277 项 |
| `python3 scripts/_tools/audit_commands.py` | 文档**命令照抄能不能跑**（命令层）：扫描全部 md 抽出命令行、清洗 markdown 记号后实跑；能抓出「命令里混进中文注释」「方括号没剥」这类照抄即报错的问题 | 12 条 |

> 只跑 `_selftest.py` 不够：它能发现"算错"，发现不了"脚本里的表与文档里的表抄得不一样"；
> 前两层也发现不了"文档命令混进中文、模型照抄就 `unrecognized arguments`"。
> 新增/修改任何固定表、算法分支或文档命令后，三个都必须绿。
>
> 项数会随脚本迭代变化，**以运行输出为准**。

## 4. 脚本不覆盖的内容

黄黑道十二神（起例版本矛盾）、二十八宿（需锚点）、宜忌与吉凶表、81 数理、
称骨、**大六壬/奇门/太乙/玄空/紫微安星**（流派分歧大或表格庞大）、**公历⇄农历换算**。
遇到这些：直接用排盘工具或让玩家查通书，**不要假装脚本算过**。

### 4.1 公历 ⇄ 农历换算（怎么拿农历月日）

**本 skill 刻意不实现农历换算**，原因不是算不了，而是：
农历初一由**日月合朔**的天文时刻决定（需月球位置 + 定朔定气规则 + 闰月判定），
硬塞进"纯标准库、零依赖"的脚本层会带来精度与维护风险，
而它的用途（主要是梅花时间起卦）完全可以用更可靠的方式拿到。

**正确做法（二选一）**：

1. **请使用者直接给出农历月日**——最省事也最不会错。
2. **调用搜索工具查权威天文机构的历算资料**——例如中国科学院紫金山天文台历算室
   每年发布的《日历资料》（含朔望两弦日期时刻表与农历日期对照）。
   查到后**照抄官方值**，并在回答里注明来源与年份。

> ⚠️ 不要凭记忆或心算推农历日期。合朔时刻有时落在日期交界附近，
> 差一小时就可能差一天，而差一天整个起卦结果就全错。
>
> ⚠️ 另一个易错点：**农历年的干支，八字按立春换、民俗按正月初一换**，两套口径不能混用。

## 5. 引用规则

1. 复核声明必须可指认：`"由 scripts/bazi.py 排出，四柱为庚午 庚辰 丁未 乙巳"`。
2. 没跑脚本就写"已复核" = 违规；跑了但年份越界（近似值），要如实说明。
3. 脚本输出里的数值原样引用，**不许在输出时"顺手改一个字"**；要改就改脚本并重跑自检。
