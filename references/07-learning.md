# 进阶学习路径（从入门到深入）

> 目标：建立「文化理解 + 可解释推理 + 理性边界」，而非神化预测。全程建议做笔记、复盘案例。

## 阶段 0：观念与伦理（3–5 天）

- 读本技能伦理条款与骗局指南。  
- 建立原则：术数=传统文化符号系统；决策=现实条件+个人选择。  
- 输出：一页「我的占卜伦理」。

## 阶段 1：基础语言（1–2 周）

必会：
1. 阴阳、五行生克  
2. 天干地支、合冲刑害  
3. 节气、农历/公历换算边界  
4. 《周易》经文大意（乾坤屯蒙…数卦即可）  

练习：手写六十甲子表；用节气定「某日属于哪个月柱」。

## 阶段 2：一技入门（2–3 月，二选一深耕）

### 路径 A：六爻（推荐问事向）
1. 《增删卜易》或《卜筮正宗》选一本 + 白话解。  
2. 练：每天 1 个虚构占题，完整装卦笔记。  
3. 复盘：写「当时判断 vs 现实反馈」（若为自己小事）。  
4. 掌握：用神、旺衰、空破、应期四类。

### 路径 B：八字（推荐一生向）
1. 先通排盘：年月日时、大运。  
2. 《子平真诠》→《滴天髓》（配讲解）。  
3. 练：给 5 个虚构命例写简批，必须写「依据」。  
4. 掌握：日主旺衰、用神、十神、岁运引发。

## 阶段 3：扩展（3–6 月）

- **梅花易数**：练物象起卦、体用。  
- **紫微斗数**：十二宫与四化。  
- **择日**：建除十二神与通书宜忌、用事分类。  
- **风水常识**：形势、采光通风动线；玄空/八宅各了解一套。  
- **姓名学**：音形义 + 五格了解即可，不神化。

## 阶段 4：式占（6–12 月+，择一）

- **奇门遁甲**：九宫八门九星八神、用神落宫、策略。  
- **大六壬**：四课三传、天将、类神。  

建议：有老师或可靠整理本；术语密，勿碎片刷短视频。

## 阶段 5：星命与冷门（选修）

- 果老星宗/七政四余（文化史价值）。  
- 铁板神数史论与辨伪。  
- 民俗占（米卦、签、扶乩）——了解文化即可。

## 阶段 6：比较、批评与表达

- 读：中国术数史、科学哲学导论、批判性思维。  
- 练习写「优缺点对比」与「场景选型」。  
- 练习**拒绝话术**（恐吓、改运、保证）。

## 阶段 7：若做内容/咨询（可选）

- 明码标价且不承诺结果；不恐吓；重大事项转介律师/医生/心理咨询。  
- 保留学习记录；持续纠偏。

## 学习方法清单

1. **手排 > 纯软件**：先手排再软件核对。  
2. **一事一记**：占题、盘面、判断、反馈。  
3. **复述**：能给外行讲明白才算懂。  
4. **写边界句**：每次解读自动带免责声明。  
5. **限频**：同一事不连占；不鼓励沉迷。  
6. **现实优先**：体检、合同、预算、沟通永远排在卦前。

## 常见学习误区

| 误区 | 纠正 |
| --- | --- |
| 背口诀不推理 | 每步写「因为…所以…」 |
| 追求铁板神断 | 回到可检验的条件句 |
| 用术数回避责任 | 结论必须落到行动 |
| 单一神准叙事 | 了解流派分歧与误判 |
| 花大钱买秘传 | 公开经典足够入门 |
| 用命理断他人隐私 | 伦理红线 |
