# 分章七：学习路径与书目

> 学与用都要先立边界：术数是传统文化、民俗与哲学研究的对象，不是科学预测工具。

## 阶段路径

1. **文化与哲思（1–2 周）**：阴阳五行、天干地支、节气；读《周易》选段（卦爻辞大意）。
2. **一技入门（2–3 月）**：优先「六爻」或「八字」二选一；跟一本经典 + 一本现代白话。
3. **算法关（贯穿）**：把 [08-algorithms.md](08-algorithms.md) 里的排盘/装卦流程跑通，
   并学会用 [09-scripts.md](09-scripts.md) 的 `scripts/` 脚本**自己把数算出来**（改脚本就跑 `_selftest.py`）；
   **手算一律用工具复核**。这一关不过，后面全是空中楼阁。
4. **实操（持续）**：排盘工具核对 + 手排；一事一卦写完整笔记（含依据链与条件句）。
5. **扩展（6 月+）**：梅花或紫微；择日与风水常识。
6. **式占（1 年+）**：奇门或六壬（术语密，择一深耕）。
7. **比较与批评**：读民俗史、科学哲学，保持理性；能指出各术优缺点。
8. **职业伦理**：若做文化讲解，不承诺改命，不恐吓收费。

**推荐顺序**：基础术语 → 六爻/八字 → 梅花/紫微 → 择日风水 → 奇门/六壬 → 星命/铁板（仅文化）。

## 工具使用原则

1. **排盘用工具，理解用手排**：八字日柱、紫微安星、奇门定局、六壬课式、玄空飞星——凡固定表与定局法，**一律用工具生成**，手排只用来验证自己是否理解规则。
2. **交叉验证**：重要结论用两个独立来源（如两本万年历、两个排盘 App）核对，不一致就说明有流派分歧，须向用户说明。
3. **不凭记忆写表**：骨重表、纳音表、星曜表、81 数理表等，记忆不可靠，转录即可能出错。

## 常见自学者踩的坑

| 坑 | 表现 | 规避 |
| --- | --- | --- |
| 节气/农历混用 | 用农历初一换月柱 | 用「节」换月、立春换年 |
| 起运数错 | 数到「中气」、或默认 3 岁 | 数到「节」；三天折一岁；岁数在 0–10 全域 |
| 大运顺逆判错 | 用日主阴阳 | 用**年干**阴阳 |
| 忘了真太阳时 | 直接用北京时间 | 经度差 ×4 分 + 均时差 |
| 梅花体用定反 | 默认上卦为体 | 动爻所在卦为用 |
| 五行克位记错 | 以为火克水 | 水克火；先确认谁克谁 |
| 数字起卦记错 | 5 当坎 | 5 = 巽，6 = 坎 |
| 卦名断吉凶 | 「既济=成」「否=凶」 | 六爻以用神旺衰断，不以卦名 |
| 星曜凭印象 | 自造命宫/对宫组合 | 实排；用「天府对宫为七杀」自检 |
| 案例数据造假 | 给真实日期却排错盘 | 案例若给日期，就必须排对 |

## 学完的标志

- 能独立排对一个八字并说明每一步依据。
- 能装一个完整的六爻卦（纳甲、世应、六亲齐全）。
- 能说清每个结论的「依据 → 判断 → 条件」，并让人复现。
- 能主动指出自己这套方法的局限，而不是越学越确信。
