# 案例教学（全部虚构）

> 所有人名、事件、数据均为虚构，仅用于展示「从起盘/起卦到结论」的推理链。不涉及真实个人。
> **凡案例中出现的排盘/起卦数据，均按 [08-algorithms.md](08-algorithms.md) 的规则逐步核算过**，非随手编造。

## 案例 1：八字 — 事业趋势简批

**人物**：虚构「苏晚」，假设排盘后日主为**甲木**，生在午月。

**十神校验**（甲木日主）：丙火 = 甲所生、同为阳 → **食神** ✓；戊土 = 甲所克、同为阳 → **偏财** ✓；庚金 = 克甲、同为阳 → **七杀** ✓。

**推理链**
1. 午月火旺，木处「休」地，木气被泄 → 假设全局生扶不足，判为中和偏弱，喜水木帮身（用神示意：水、木）。
2. 食神生财：才华可变现，适合内容、设计、教学。
3. 七杀有食制：压力大但能扛，宜目标清晰的团队。
4. 若大运走水木：贵人、学习；若大运火土过旺：透支、多线开花。

**结论**：「宜深耕一门可展示的作品，忌同时追三个风口。」
**边界**：职业选择仍取决于技能、市场与个人意愿；旺衰与用神各派判断可能不同。

## 案例 2：紫微 — 问迁移与出行

**人物**：虚构「郑帆」，命宫**天机**，三方四正之内见**天梁化禄**（示意）。

> ⚠️ 星曜落宫必须按生辰实排。此处只说「三方四正之内」（本宫 + 对宫 + 三合两宫），不指定天梁落在哪宫——命宫与对宫的组合有固定规则，凭印象指定极易出错。实排后自检：**天府的对宫恒为七杀**。

**推理链**
1. 命宫天机：思维快、变动多。
2. 三方四正见化禄：外出、异地机会的助力较明显。
3. 若再见文昌文曲：文书、考试、资质在路上更重要。

**结论**：「若去外地求学/项目，优先选有正规文书与学习资源的平台；出行前把手续办全。」
**边界**：不承诺「出外必发达」。

## 案例 3：六爻 — 问「是否接受这个 offer」

**占题**：「虚构：是否接受 B 公司产品经理 offer，两周内答复。」
**起卦示意**：本卦「**泽火革**」（兑上离下）变「**水火既济**」（坎上离下）。
- 校验：兑（阳、阳、阴）→ 坎（阴、阳、阴）为初爻由阳转阴，即**四爻动**（上卦初爻），变卦既济成立 ✓。

**用神**：问工作取**官鬼**；世爻为求测人。

**推理链**
1. 官鬼旺相有气 → 机会真实（以用神断，不凭卦名）。
2. 世应相合但间爻发动 → 中间条款（汇报线/薪资结构）有拉扯。
3. 四爻发动且恰临世爻 → 自己这边有动作，宜主动争取。
4. 应期：动爻逢值合之日利签约。

**结论**：「可以争取，先书面确认汇报关系与奖金规则。」
**边界**：劳动合同请按法律与 HR 正式文本。

## 案例 4：梅花 — 寻物（钥匙）

**情景**：虚构「钥匙不见了」，以报数 **8、7** 起卦。

**起卦核算**
- 上卦 = 8 → **坤**；下卦 = 7 → **艮**；本卦「**地山谦**」（坤上艮下）。
- 动爻 =(8+7) mod 6 = 15 mod 6 = **3**，三爻动，**落在下卦**。
- 体用：下卦有动爻 → 下卦艮为**用卦**，上卦坤为**体卦**。体 = 坤（土），用 = 艮（土）→ **体用比和**。
- 互卦：二三四爻 = 阴、阳、阴 = 坎；三四五爻 = 阳、阴、阴 = 震 → **雷水解**，见坎（暗、陷、压在下面）。
- 变卦：三爻阳转阴，下卦艮（阴、阴、阳）成坤（阴、阴、阴）→ **坤为地**。

**推理链**
1. 体用比和 → 物未远、未离手边范围。
2. 艮为山为桌几、坤为方为容器 → 抽屉、柜子、包内侧袋。
3. 互卦见坎 → 压在书本/杂物下，或光线暗处。
4. 变卦纯坤 → 落在低处、方正容器中。

**结论**：「往西南方位的桌面、柜子与最近用过的包里找；两小时内范围最大。」
**边界**：象数联想，不保证找到；方位取法各派有别。

## 案例 5：周易卦辞 — 问「该不该现在转型」

**得卦**：「渐」（风山渐）。

**推理链**
1. 渐者，进也，循序。
2. 爻辞意象：鸿渐于干→于磐→于陆…（由低到高）。

**结论**：「转型宜分阶段：先兼职验证，再全职；忌一夜 all in。」
**边界**：古典哲学启发。

## 案例 6：奇门 — 问「何时发布作品」

**示意**（须用排盘工具生成实盘）：景门（传播、文书）旺，日干得地，但螣蛇临（反复修改欲）。

**推理链**
1. 景门利展示、传播。
2. 螣蛇主反复 → 自己拖延风险高于外界风险。
3. 选天辅/天心值日相对稳。

**结论**：「先定一个不可撤回的发布日；发布当天不临场改文案。」
**边界**：时机建议，市场反馈无法保证。

## 案例 7：大六壬（示意简课）— 问「失物」

**示意**：初传见玄武（盗失/暗）临支，末传见寻物类神得气。

**推理链**
1. 玄武主失脱、方位暗。
2. 末传得气 → 可复得，宜从近处与「暗格」找。

**结论**：「先查非公开收纳处；若疑被盗则走法律/安保渠道。」
**边界**：课例教学化简，真实六壬排课更繁，须用排盘工具。

## 案例 8：面相 + 言行 — 合作判断

**观察**：虚构对象「目光平稳、应答有停顿、承诺留书面」。

**推理链**
1. 言行一致风险低。
2. 面相仅作气质补充，不以单点定人品。

**结论**：「合作可试点小项目，分阶段付款。」
**边界**：以合同与履历为准。

## 案例 14：拒绝恐吓式占断

**用户**：「大师说我今年有血光之灾，怎么化解？」
**正确回应结构**：
1. 不认可灾祸恐吓话术。
2. 说明常见诈骗模式（必消灾）。
3. 给真实风险建议：体检、安全驾驶、应急联系人。
4. 若焦虑明显，建议心理咨询/医疗。
5. 可提供文化科普，不卖法器。
