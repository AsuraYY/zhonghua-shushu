# 分章一：命理推命类

> 边界：命理属传统文化与民俗参考，不构成婚姻、职业、健康等重大决策依据。案例均虚构。

## 1. 四柱八字（子平术）

### 原理
以出生的**年、月、日、时**四组干支（各一干一支，共八字）描述一个人出生时刻的五行（金木水火土）气候结构，再通过**十神**关系推演六亲、事业、性情与大运流年的起伏。

- **天干地支**：十天干（甲乙丙丁戊己庚辛壬癸）+ 十二地支（子丑寅卯辰巳午未申酉戌亥）。
- **五行生克**：木生火，火生土，土生金，金生水，水生木；相克为木克土、土克水、水克火、火克金、金克木。
- **节气定月**：月份以「节」为界（立春、惊蛰、清明…），不是农历初一；年柱以**立春**换年。
- **日主（日干）**：日柱天干代表命主自身，其余七字对日主产生生、克、同、泄、耗关系，构成十神。

### 术语表（白话）

| 术语 | 白话 |
| --- | --- |
| 日主 / 日元 | 代表「我」的那个天干 |
| 比肩、劫财 | 与我同类的五行，朋友、竞争 |
| 食神、伤官 | 我生者，才华、表达、子女星（男命看法有流派差异） |
| 正财、偏财 | 我克者，钱财、务实 |
| 正官、七杀 | 克我者，事业、规则、压力 |
| 正印、偏印 | 生我者，学习、母亲、庇护 |
| 用神 | 最能使命局趋于平衡、对命主有利的五行 |
| 忌神 | 对平衡不利、宜回避的五行 |
| 旺衰 | 日主在月令及全局中的强弱 |
| 大运 | 约十年一换的运干支，人生阶段气候 |
| 流年 | 当年的干支，引发具体事件 |
| 刑冲合害 | 地支之间的关系，常表示变动、引动 |
| 空亡 | 日柱旬空，表示暂时落空、延迟（六爻更常用） |

### 操作流程（排盘 step-by-step）

1. **确认时间**：公历出生日期、尽量精确的出生时间、出生地（用于真太阳时与子时争议）。
2. **换节气月**：用节气表定月柱地支（寅月自立春起…）。
3. **定年柱**：立春前出生算上一年。
4. **定日柱**：查万年历或日柱公式（儒略日推算）。
5. **定时柱**：用「五鼠遁」日上起时（甲己还加甲，乙庚丙作初…）；23:00–24:00 是否算次日子时，需注明流派。
6. **排大运**：阳男阴女顺排、阴男阳女逆排，从月柱起，一般 3 岁起运（精确起运岁数需算节气天数）。
7. **标十神与藏干**：给每个天干标十神，地支藏干也标出。
8. **判旺衰与用神**：看月令、通根、生扶与克泄耗。
9. **对大运流年**：看喜用被引动还是忌神被引动。

### 解读逻辑（模板骨架）
1. 日主是谁、旺衰如何  
2. 命局最大的 1–2 组十神关系（如「官印相生」「食神制杀」）  
3. 用神喜忌  
4. 性情优势与易踩的坑（忌神相关）  
5. 近年大运/流年：机遇与注意点  
6. 行动建议 + 边界声明  

### 案例（虚构）
- **命主**：虚构「林小满」，公历 1990-04-12 上午 10:30（示意）。
- **排盘示意**：日主假设为**庚金**，生在辰月，土旺金相，身偏强。
- **十神**：透出丙火七杀、戊土偏印、乙木正财。
- **推理链**：身强喜财官泄耗 → 丙火七杀为用但需财生杀 → 大运若行木火，事业推进；行金土则竞争与固执增加。
- **结论示例**：「适合有规则、有压力的目标型工作；宜主动争取项目，忌多头并进、完美主义拖期。」
- **边界**：「这是命理框架的性格与趋势参考，职业选择仍取决于技能、市场与你的选择。」

### 经典书目
- 入门白话：现代子平教材任选一本系统者  
- 《渊海子平》《三命通会》《子平真诠》《滴天髓》  
- 工具：万年历/排盘软件（用于核对手排）

## 2. 紫微斗数

### 原理
以农历（或通过干支排盘）的生辰安十四主星于十二宫，辅以辅星、煞星、四化（禄权科忌），用**三方四正**看宫位联动，推人生领域。

### 十二宫（白话）
命宫（我）、兄弟、夫妻、子女、财帛、疾厄、迁移、仆役（交友）、官禄（事业）、田宅、福德、父母。

### 关键概念
- **主星**：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军。
- **四化**：化禄（缘、收获）、化权（掌控、推动）、化科（名誉、解）、化忌（牵挂、损失、执着）。
- **三方四正**：本宫 + 对宫 + 三合两宫，共看。
- **庙旺利陷**：星曜在不同地支的状态，影响表现力。

### 操作流程
1. 转农历生辰，定命宫与身宫位置。  
2. 安十四主星与辅佐煞星（按安星诀）。  
3. 起四化（依生年天干）。  
4. 以命宫三方四正为纲，再看事业、财帛、夫妻等宫。  
5. 结合大限（约十年）、流年宫看阶段。

### 解读逻辑
- 先讲命宫格局气质，再讲最关心的一两个宫（用户问什么看什么）。  
- 四化落入何宫 = 把能量投到哪里。  
- 不把单星当判决书；强调组合与后天选择。

### 案例（虚构）
- **设定**：虚构「周予安」，命宫天府+禄存，官禄宫紫微化权。
- **推理**：命宫主稳健、资源整合；官禄得权，事业上容易被委以责任。
- **结论**：「适合平台型、管理协调类角色；忌事必躬亲导致的倦怠，宜建立可复制的流程。」
- **边界**：非职业测评。

### 经典书目
《紫微斗数全书》《太微赋》《骨髓赋》《诸星问答论》

## 3. 铁板神数

### 原理与争议
传为宋代邵雍（邵康节）体系，以「条文」数序（如某数对应某段断语）推人生细节，擅长六亲、子女数等条目化描述。

**必须标注的传承争议**：
1. 是否存在「全本」秘传，版本不一。  
2. 起数钥匙（考时定刻、加减卦数）多种，细节互斥。  
3. 部分现代产品将固定条文包装成「神断」营销。  
4. 学界多视为托名与层累形成之术，**不宜神化**。

### 用途边界
仅作文化史与民俗介绍；不承诺「一口断准六亲」；不参与相关付费秘传班营销。

## 4. 简易推命类

### 称骨算命
- **方法**：年、月、日、时各对应骨重（两/钱），加总查歌诀。  
- **特点**：操作极简，批语笼统。  
- **用法**：娱乐、科普五行概念；**不作人生判词**。

### 达摩一掌经
- 从年月日时推「六道」（佛道、仙道、人道、修罗、畜生、饿鬼等象征）属民俗托名达摩。  
- 适合讲「民间如何用宗教意象分类命运」，不适合宿命标签。

### 鬼谷子算命 / 两头钳
- 以干支组合取固定批语（如某年某时对应某段话）。  
- 批文文学性强，逻辑固定，细节预测力弱。

### 简易类共用解读模板
1. 说明这是简化民俗算法  
2. 给出计算过程（骨重或干支）  
3. 解释批文在讲什么倾向  
4. 明确娱乐向 + 事在人为

## 命理类对比

| 体系 | 看重 | 优点 | 缺点 | 适用 |
| --- | --- | --- | --- | --- |
| 八字 | 五行结构与运 | 逻辑链完整、可讲理 | 精确度依赖排盘与用神水平 | 性格、趋势、合参 |
| 紫微 | 宫位与星曜 | 领域划分清楚 | 安星规则多、流派多 | 人生分项 |
| 铁板 | 条文 | 故事性强 | 传承争议 | 文化介绍 |
| 称骨等 | 总重/干支句 | 上手快 | 粗糙 | 娱乐科普 |
