# 分章一：命理推命类

> 边界：命理属传统文化与民俗参考，不构成婚姻、职业、健康等重大决策依据。案例均虚构。
> **排盘算法见 [08-algorithms.md](08-algorithms.md) A 节**（五虎遁、五鼠遁、日柱公式、真太阳时、起运折算、藏干表），本文只讲原理与解读，不重复算法。

## 1. 四柱八字（子平术）

### 原理
以出生的**年、月、日、时**四组干支（各一干一支，共八字）描述一个人出生时刻的五行（金木水火土）气候结构，再通过**十神**关系推演六亲、事业、性情与大运流年的起伏。

- **天干地支**：十天干（甲乙丙丁戊己庚辛壬癸）+ 十二地支（子丑寅卯辰巳午未申酉戌亥）。
- **五行生克**：木生火，火生土，土生金，金生水，水生木；相克为木克土、土克水、水克火、火克金、金克木。
- **节气定月**：月份以「节」为界（立春、惊蛰、清明…），**不是农历初一**；年柱以**立春**换年。
- **日主（日干）**：日柱天干代表命主自身，其余七字对日主产生生、克、同、泄、耗关系，构成十神。

### 术语表（白话）

| 术语 | 白话 |
| --- | --- |
| 日主 / 日元 | 代表「我」的那个天干 |
| 比肩、劫财 | 与我同类的五行，朋友、竞争 |
| 食神、伤官 | 我生者，才华、表达；女命以食伤看子女，男命传统以官杀看子女（流派有别） |
| 正财、偏财 | 我克者，钱财、务实 |
| 正官、七杀 | 克我者，事业、规则、压力 |
| 正印、偏印 | 生我者，学习、母亲、庇护 |
| 用神 | 最能使命局趋于平衡、对命主有利的五行 |
| 忌神 | 对平衡不利、宜回避的五行 |
| 旺衰 | 日主在月令及全局中的强弱 |
| 大运 | 约十年一换的运干支，人生阶段气候 |
| 流年 | 当年的干支，引发具体事件 |
| 刑冲合害 | 地支之间的关系，常表示变动、引动 |
| 空亡 | 该旬所缺的两个地支；八字多从日柱查（亦有年柱派），六爻从起卦日查，二者不混用 |

### 操作流程（排盘 step-by-step）

1. **确认时间**：公历出生日期、尽量精确的出生时间、出生地（经度）。
2. **真太阳时校正**：北京时间 +（当地经度 − 120°）× 4 分 + 均时差。
3. **定年柱**：立春前出生算上一年。
4. **换节气月**：用「节」定月柱地支，再用**五虎遁**定天干（寅月自丙/戊/庚/壬/甲起，依年干）。
5. **定日柱**：查万年历/排盘库，或用 JDN 公式。
6. **定时柱**：地支按时辰段，**五鼠遁**日上起时定天干；23:00–24:00 是否算次日子时，需注明流派。
7. **排大运**：阳年干男命、阴年干女命顺排；阴年干男命、阳年干女命逆排；从月柱起；**三天折一岁**，数到「节」而非中气。
8. **标十神与藏干**：给每个天干标十神，地支藏干也标出。
9. **判旺衰与用神**：看月令、通根、生扶与克泄耗。
10. **对大运流年**：看喜用被引动还是忌神被引动。

> ⚠️ 起运岁数在 **0–10 岁全域分布**，没有默认值，必须实算。

### 解读逻辑（模板骨架）
1. 日主是谁、旺衰如何
2. 命局最大的 1–2 组十神关系（如「官印相生」「食神制杀」「食伤生财」）
3. 用神喜忌
4. 性情优势与易踩的坑（忌神相关）
5. 近年大运/流年：机遇与注意点
6. 行动建议 + 边界声明

### 案例（虚构·数据经排盘库实测）

- **命主**：虚构「林小满」，公历 **1990-04-12 上午 10:30**，出生地按东经 120° 计（经度时差为 0）。
  > ⚠️ 口径说明：`scripts/bazi.py` 即使经度为 120°，仍会叠加**均时差**（本例 −1.1 分 → 真太阳时 10:28）。
  > 本例四柱与时柱都不受影响，故两种口径结果一致；**但凡真太阳时临近时辰/日期边界，一律以脚本输出为准**，不要按"东经 120° 就不校正"想当然。
- **实测四柱**：

|  | 年柱 | 月柱 | 日柱 | 时柱 |
| --- | --- | --- | --- | --- |
| 干支 | 庚午 | 庚辰 | **丁未** | 乙巳 |
| 十神（对日主丁火） | 正财 | 正财 | **日主** | 偏印 |
| 支藏 | 丁、己 | 戊、乙、癸 | 己、丁、乙 | 丙、庚、戊 |

- **排盘校验**：1990 立春 2/4 → 庚午年 ✓；4/12 在清明后、立夏前 → 辰月，庚年五虎遁得**庚辰** ✓；日柱实测**丁未** ✓；丁日五鼠遁，巳时得**乙巳** ✓。
- **日主**：**丁火**，生辰月（土当令，火为「休」）。
- **结构**：天干双庚正财透出，乙木偏印透时干；地支午、未、巳皆藏火（午丁、未丁、巳丙），日主有根有生，不作弱论；辰未土为食伤泄秀，庚金财星透干且巳中藏庚为根 → **食伤生财**之象。
- **推理链**：身有根气、食伤泄秀生财 → 宜凭专业/作品变现，靠持续输出换收益；财透两头，宜明码实价、先签后做。若行土金之运，食伤财星得力，产出与收入同步走高；若行木火过旺之运，印比助身太过，易多头并进、投入大于产出。
- **起运（示意）**：庚午年（庚为阳干）→ 男命顺排、女命逆排。实测男命约 **7 岁 10 月**起运（辛巳→壬午→癸未…），女命约 **2 岁 4 月**起运（己卯→戊寅→丁丑…）。
- **结论示例**：「适合把技能沉淀成可交付的作品，收入靠复购与口碑；忌同时铺三个方向、忌口头承诺不留凭证。」
- **边界**：「这是命理框架的性格与趋势参考，职业选择仍取决于技能、市场与你的选择。旺衰与用神各派看法不一，此处仅为一种解读路径。」

### 经典书目
- 入门白话：现代子平教材任选一本系统者
- 《渊海子平》《三命通会》《子平真诠》《滴天髓》
- 工具：万年历/排盘软件（**用于核对手排，不可只信手算**）；排盘优先跑 `scripts/bazi.py`（见 [09-scripts.md](09-scripts.md)）

## 2. 紫微斗数

### 原理
以农历（或通过干支排盘）的生辰安十四主星于十二宫，辅以辅星、煞星、四化（禄权科忌），用**三方四正**看宫位联动，推人生领域。

### 十二宫（白话）
命宫（我）、兄弟、夫妻、子女、财帛、疾厄、迁移、仆役（交友）、官禄（事业）、田宅、福德、父母。

### 关键概念
- **主星（14 颗）**：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军。
- **四化**：化禄（缘、收获）、化权（掌控、推动）、化科（名誉、解）、化忌（牵挂、损失、执着）。依生年天干起。
- **三方四正**：本宫 + 对宫 + 三合两宫，共看四宫。
- **庙旺利陷**：星曜在不同地支的状态，影响表现力。

### 操作流程
1. 转农历生辰，定命宫与身宫位置。
2. 安十四主星与辅佐煞星（按安星诀）。
3. 起四化（依生年天干）。
4. 以命宫三方四正为纲，再看事业、财帛、夫妻等宫。
5. 结合大限（约十年）、流年宫看阶段。

> ⚠️ **星曜落宫一律实排，不得凭印象编造。** 自检：天府的对宫恒为**七杀**，若排出的盘不满足，说明排错了。详见 [08](08-algorithms.md) D 节。

### 解读逻辑
- 先讲命宫格局气质，再讲最关心的一两个宫（用户问什么看什么）。
- 四化落入何宫 = 把能量投到哪里。
- 不把单星当判决书；强调组合与后天选择。

### 案例（虚构）
- **设定**：虚构「周予安」，命宫天府 + 禄存，官禄宫紫微化权（示意性设定，实际须按生辰实排）。
- **推理**：命宫主稳健、资源整合；官禄得权，事业上容易被委以责任。
- **结论**：「适合平台型、管理协调类角色；忌事必躬亲导致的倦怠，宜建立可复制的流程。」
- **边界**：非职业测评。

### 经典书目
《紫微斗数全书》《太微赋》《骨髓赋》《诸星问答论》

## 3. 铁板神数

### 原理与争议
传为宋代邵雍（邵康节）体系，以「条文」数序（如某数对应某段断语）推人生细节，擅长六亲、子女数等条目化描述。

**必须标注的传承争议**：
1. 是否存在「全本」秘传，版本不一。
2. 起数钥匙（考时定刻、加减卦数）多种，细节互斥。
3. 部分现代产品将固定条文包装成「神断」营销。
4. 学界多视为托名与层累形成之术，**不宜神化**。

### 用途边界
仅作文化史与民俗介绍；不承诺「一口断准六亲」；不参与相关付费秘传班营销。

## 4. 简易推命类

### 称骨算命
- **方法**：年（六十甲子）、月、日、时各对应骨重（两/钱），加总后查歌诀。
- **⚠️ 本技能不内置完整骨重表**：各版本数值有出入，凭记忆转录易错。实算请查《袁天罡称骨歌》原表或权威排盘工具。
- **特点**：操作极简，批语笼统。**娱乐、科普五行概念；不作人生判词。**

### 达摩一掌经
- 从年月日时推「六道」（佛道、仙道、人道、修罗、畜生、饿鬼等象征）属民俗托名达摩。
- 适合讲「民间如何用宗教意象分类命运」，不适合宿命标签。

### 鬼谷子算命 / 两头钳
- 以干支组合取固定批语（如某年某时对应某段话）。
- 批文文学性强，逻辑固定，细节预测力弱。

### 简易类共用解读模板
1. 说明这是简化民俗算法
2. 给出计算过程（骨重或干支），并注明所用版本
3. 解释批文在讲什么倾向
4. 明确娱乐向 + 事在人为

## 命理类对比

| 体系 | 看重 | 优点 | 缺点 | 适用 |
| --- | --- | --- | --- | --- |
| 八字 | 五行结构与运 | 逻辑链完整、可讲理 | 精确度依赖排盘与用神水平 | 性格、趋势、合参 |
| 紫微 | 宫位与星曜 | 领域划分清楚 | 安星规则多、流派多，易排错 | 人生分项 |

| 称骨等 | 总重/干支句 | 上手快 | 粗糙、版本不一 | 娱乐科普 |
