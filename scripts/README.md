# scripts/ —— 中华术数「确定性计算」脚本层

> 一句话：**排盘、装卦、起卦这类"可机械推导"的活，一律跑脚本；模型只负责解读与表述。**
> 这样既省算力，也避免模型在心算/背表时出错。

---

## 1. 运行方式

零依赖、纯 Python 标准库。用任意 Python 3.8+ 直接跑：

```bash
# Windows（用你自己的 python 路径）
python scripts/bazi.py --datetime "1990-04-12 10:30" --gender male

# macOS / Linux
python3 scripts/bazi.py --datetime "1990-04-12 10:30" --gender male
```

- 所有脚本 **`--help`** 可见完整参数。
- 多数脚本支持 **`--json`**，输出结构化结果便于上层解析。
- 脚本之间独立，互不依赖；公共部分在 `_common.py` / `_bagua.py` / `_astro.py`。

升级或修改脚本后，**三道校验都要跑**：

```bash
python3 scripts/_selftest.py                 # 数值层：脚本算得对不对（48 项）
python3 scripts/_tools/audit_vs_doc.py       # 文档层：脚本常量与 08-algorithms.md 表格逐格一致（277 项）
python3 scripts/_tools/audit_commands.py     # 命令层：文档里写的命令照抄能不能跑通
```

只跑 `_selftest.py` 不够——它查不出「脚本里的固定表与文档里的表抄得不一样」；
前两层也查不出「文档命令里混进中文注释、模型照抄就报错」。

## 3. 数据来源与精度（重要，别跳过）

### 3.1 节气时刻 —— 查表，不手算

`scripts/data/solar_terms_1900_2052.csv` 是**预先算好的**，
每行一年，每列一个节气，值为"该年 1 月 1 日起的第几分钟（北京时间）"。

- 生成方式：JPL **DE421 星历**（经 Skyfield 读取）→ 太阳**视黄经**（含光行差与章动，
  基准为当日真分点）二分逼近至 1e-9 日 → 按 ΔT（TT−UT1）折算北京时间。
- 生成脚本：`scripts/_tools/gen_solar_terms.py`（只在重建数据时用，需 `pip install skyfield numpy` 与 DE421 文件）。
- **对校结果**：2026 年 24 个节气与公开发布的万年历秒值相比，**最大偏差 34 秒**；
  与日本国立天文台《暦要項》令和 8 年（JST 整分值）亦一致。
- 覆盖 **1900–2052**（受 DE421 星历覆盖期限制）。超出该范围的年份会退回
  `_astro.py` 里的近似太阳黄经公式，并**显式打印「近似值」警告**，
  误差可达十余分钟 —— 此时涉及节气边界的判断必须提示用户以通书核对。

### 3.2 真太阳时

经度时差 =（当地经度 − 120°）× 4 分钟；均时差用常用近似式（年较差约 ±0.6 分钟）。
默认做校正，`--no-solar-time` 可关闭。**经度尽量由用户给出**（`--lon`），
`--city` 只做兜底近似（市区中心粗略值，表在 `_astro.py: CITY_LON`）。

### 3.3 干支 / 六十四卦

- 日柱：儒略日公式（08 A3），锚点 `2000-01-07 = 甲子`，已用
  1949-10-01 甲子 / 2000-01-01 戊午 / 2024-02-10 甲辰 三点交叉校验。
- 六十四卦名 **不是手抄的**，而是由「八宫表 + 京房爻变规则」推导生成
  （`_bagua.py: build_gua_table`），保证卦名、上下卦、卦宫、世应不会互相对错。
- 纳音表经外部权威资料交叉核对，按下表取正字，异写仅供识别：

| 本脚本用 | 常见异写 |

## 4. 刻意不做的部分（避免"看起来很全"的假象）

以下内容**没有**脚本实现，遇到就用通书/专业工具，别让模型硬算：

| 项目 | 不做的原因 |
| --- | --- |
| **黄黑道十二神** | 起例版本互相打架（"寅申月起子"与"建日为青龙"两套并存的矛盾），实现哪家都可能错 |
| **二十八宿** | 需绝对锚点，各版本相位不同 |
| **宜忌 / 吉凶判断表** | 本 skill 不内置宜忌表，且宜忌属民俗判断 |
| **81 数理吉凶** | 固定附会，无预测效力（08 G） |
| **称骨、六壬、奇门、太乙、玄空、紫微安星** | 流派分歧大或表格庞大，08 F 节已明确"须用工具" |
| **公历 ⇄ 农历换算** | 未实现；梅花时间起卦须由使用者提供农历月日 |

另外，语言/区位差异常导致边界差异，**脚本统一采用以下口径**，解读时应说明：

- 立春换年、**节**（非中气）换月、五虎遁/五鼠遁、三天折一岁；
- 23:00–24:00 默认归次日（夜子时随次日），`--zishi same` 可切"归当日"；
- 六神按日干起例、**自初爻向上顺排**（《卜筮正宗》一系），另有按卦宫阴阳逆排的流派。

## 5. 给自己的红线

1. **引用脚本输出时照抄数值，不要"顺手修正"。** 若与直觉不符，先怀疑口径设定（经度、子时政策、是否校正）。
2. **不得给曾经的"手算"背书**：没有跑脚本就说"已复核"，是违规；写了"脚本复核"就必须能指认脚本名与关键输出。
3. **脚本只出数值，不出吉凶**。断语由模型按 references 的规则表述，并保留边界声明。
